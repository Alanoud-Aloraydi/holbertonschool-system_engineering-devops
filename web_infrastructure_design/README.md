# Web infrastructure design

Whiteboard designs for the web infrastructure project. Each task has one answer file. Every diagram is drawn on a whiteboard or a diagram tool, then uploaded to an image host, and its link is inserted in the answer file.

## Files

- `0-simple_web_stack`: one server, Nginx, application server, MySQL.
- `1-distributed_web_infrastructure`: HAProxy load balancer and two application servers.
- `2-secured_and_monitored_web_infrastructure`: firewalls, HTTPS and monitoring.
- `3-scale_up`: load balancer cluster, one added server, and components split onto their own servers.
